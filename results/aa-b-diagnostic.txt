
==========================================================================================
Family (a,a,b): diagnostic for Laplacian non-integrality
==========================================================================================
Cubic: f(x) = x^3 - E1 x^2 + E2 x - E3, with
  E1 = 2a^2 + 5ab + 3a + b
  E2 = a^4 + 7a^3 b + 3a^3 + 8a^2 b^2 + 11a^2 b + 2a^2
       + 3a b^2 + 2ab
  E3 = 2a^2 b (a+b+1)(a^2 + 2ab + 2a + b)

Columns:
  int roots    : integer roots of f_{a,b}
  irrational?  : True iff f_{a,b} has an irreducible factor
                 of degree >= 2 over Q
  factor deg   : degrees of the irreducible factors
  trapped?     : True iff some real root lies strictly
                 between two consecutive integers
  trap value   : consecutive integer endpoints, certified by exact root isolation
  p_irr        : smallest tested prime (among 2..31) with f mod p irreducible

==========================================================================================
Summary
==========================================================================================
a = 2, b = 1..30: irrational in 30/30, trapped in 30/30
a = 3, b = 1..30: irrational in 30/30, trapped in 30/30
a = 4, b = 1..30: irrational in 30/30, trapped in 30/30

Interpretation:
  - If 'irrational?' is True for all (a,b), the cubic always
    has a non-integer root, so the graph is not integral.
  - If 'trapped?' is True for all (a,b), the non-integer root
    is always located between two consecutive integers.
  - If 'p_irr' is a small prime for all (a,b), a modular
    irreducibility argument may close the family.
