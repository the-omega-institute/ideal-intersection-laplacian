# Collaboration working agreements

- Read README.md and RESEARCH-PLAN.md before continuing this track.
- Preserve collaborator edits and work in an independent checkout when needed.
- Keep unannounced source manuscripts, private correspondence and credentials outside this public repository.
- Check the graph definition and hypotheses before using a spectral formula.
- Distinguish prior results, new written proofs, exact finite calculations and Lean verification.
- Do not present numerical eigenvalue approximations as exact integrality evidence.
- Use computations to resolve a stated mathematical question; do not expand searches without a purpose.
- Before Lean work, confirm the current session's machine, measure memory and enumerate active lean/lake executables by comm basename.
- Do not change shared CI to resolve a one-off verification need.
- Record exact commits, validation scope and next steps in the private collaboration tracker.
- Authorship and disclosure changes require the authors' agreement; publication and merges require explicit user authorization.
